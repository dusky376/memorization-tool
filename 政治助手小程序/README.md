# 政治背诵 - 微信小程序（体验版）

配套电脑端 `E:\workspace\政治助手\`（Flask, 端口 8686）使用，**后端零改动**，手机扫码即可背题。

## 一、项目结构
```
政治助手小程序/
├── app.js / app.json / app.wxss      全局入口 / 5页注册+4tab / 全局样式
├── config.js                          唯一要改的配置：LAN_IP（电脑局域网 IP）
├── project.config.json                appid 预填测试号 touristappid
├── utils/api.js                       全部业务逻辑 + API 封装（node 可直接单测）
├── pages/
│   ├── recite/    背诵：全库默背 / 今日卡片（点击遮挡、输入填空、认识忘了）
│   ├── add/       录入：拍照选图上传识别、聊天选 PDF/Word、挖空助手、编辑模式
│   ├── arrange/   整理：inbox 草稿核对入库、已忽略留痕恢复（8 秒自动刷新）
│   ├── manage/    管理：搜索 / 科目筛选 / 排序 / 编辑 / 删除
│   └── help/      使用说明（从管理页进入）
├── images/tab/    4 组 tabBar 图标
└── test/          自测脚本（不参与小程序运行）
```

## 二、第一次跑起来（开发者工具）
1. 电脑端先把服务跑起来：`python E:\workspace\政治助手\server.py`（或按政治助手项目习惯的后台方式），浏览器开 `http://127.0.0.1:8686` 确认正常。
2. 装微信开发者工具（官网 Stable 版），微信扫码登录。
3. 「导入项目」→ 目录选 `E:\workspace\政治助手小程序` → AppID 用预填的**测试号**（touristappid，无需注册）。
4. 详情 → 本地设置 → 勾选「**不校验合法域名**」（project.config.json 里已预置 `urlCheck:false`，换电脑导入时再确认一次）。
5. 模拟器直接可用——开发者工具里自动走 `http://127.0.0.1:8686`（api.js 按 `platform==='devtools'` 区分）。

## 三、真机预览（鸿蒙微信一样跑）
1. 手机和电脑连**同一个 WiFi**。
2. 开发者工具点「**预览**」→ 手机微信扫码（预览码约 30 分钟有效，过期重生成）。
3. 若请求失败：小程序右上角「…」→ 里找到「**开发调试**」打开 → 重新进入（放行 http 请求；鸿蒙版微信路径相同，找不到这个开关就翻「开发」子菜单）。
4. 电脑换了 IP：电脑 cmd 跑 `ipconfig` 看「IPv4 地址」→ 改 `config.js` 的 `LAN_IP` 一行 → 工具里重新编译、重新扫预览码。
5. 电脑防火墙拦了：给 `python.exe` 放行 8686 入站（之前手机网页版能通就说明已放行过）。

## 四、体验版（可选，长期用才需要）
> 测试号（游客模式）**只能预览/真机调试，不能上传体验版**。要体验版需注册免费的个人小程序账号：
1. `mp.weixin.qq.com` 注册 → 拿正式 **AppID** → 替换 `project.config.json` 里的 `touristappid`。
2. 开发者工具「上传」→ 填版本号（如 1.0.0）。
3. 公众平台后台「版本管理」→ 选刚上传的版本设为**体验版** → 下载体验版二维码。
4. 鸿蒙/安卓微信扫码进入体验版 → 右上角「…」→ **开发调试**打开 → 正常使用（体验版仍需此开关放行 http）。
5. 手机端入口：不再依赖扫码，在最近使用小程序列表里能找到。

## 五、日常使用的两条数据路
- **手机路**：【录入】拍照/选图（一次最多 9 张）→ 自动识别并按红标挖空 → 保存入库 → 【背诵】开背。
- **电脑路**：截图/PDF/Word 丢进电脑的 `inbox` 文件夹 → 5 秒自动出草稿 → 手机【整理】页核对入库；重复文件自动拦截，在「已忽略」留痕、可恢复。
- PDF/Word 在手机端：先发给文件传输助手 → 【录入】页「从聊天选 PDF/Word」。

## 七、已知边界
- 小程序只在**局域网**用（和电脑同 WiFi）；出门在外暂用不了。
- 鸿蒙版微信个别 API 支持情况未经检索确认（websearch 不可用），已做防御式处理：不支持的功能**不隐藏入口就是降级提示**，遇到报错按提示排查。
- 词条/图片数据全在你自己电脑上，小程序不连任何云。
